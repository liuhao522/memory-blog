# 智慧工牌平台 — 新手上手指南

## 一、平台概述

**智慧工牌平台** 是一套面向企业语音/工牌设备管理的综合性 SaaS 平台。基于 BladeX 微服务架构（后端）和 Saber3 低代码框架（前端）构建。

### 1.1 核心能力全景

| 业务域 | 模块 | 功能简述 |
|--------|------|----------|
| 🏢 系统管理 | system | 用户/角色/菜单/部门/租户/字典/参数/岗位 |
| 📱 设备管理 | device | 设备信息/GPS/日志/录音/声纹/打卡/告警/案例库 |
| 🎛️ 设备控制 | record | 远程控制(录音/重启/定位)、心跳监控、配置下发 |
| 📞 对讲管理 | talk | 对讲模型/用户/设备绑定 |
| 🤖 AI质检 | quality | 质检模型/维度/细则/扣分/行业配置 |
| 📊 AI分析 | quality (VOC) | 通用分析/行业分析/客户洞察/质检结果 |
| 💬 AI对话 | quality (Chat) | OpenAI对话/聊天记录/Dify日志 |
| 📋 工作流 | flow + work | 请假流程/申诉流程/BPMN模型设计/部署/任务 |
| 📈 报表分析 | desk + analysis | 仪表盘/客服报表/质检报表/标签分析 |
| 🔗 第三方集成 | thirdparty | 第三方API/订单管理/套餐/发货 |
| 🛠️ 开发运维 | ops (develop/job/log/resource) | 代码生成/任务调度/日志管理/附件/OSS/短信 |

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────┐
│                   Saber3 前端 (Vue 3)                │
│   Element Plus + Avue 低代码 + AMap 2.0             │
├─────────────────────────────────────────────────────┤
│                  BladeX Gateway (网关)               │
├──────────┬──────────┬──────────┬───────────────────┤
│ blade-   │ blade-   │ blade-   │ blade-ops         │
│ service  │ record   │ quality  │ (develop/flow/    │
│ (system/ │ (设备通信) │ (AI质检)  │  job/log/resource)│
│  device/ │          │          │                   │
│  desk/   │          │          │                   │
│  talk/   │          │          │                   │
│  3rdpty) │          │          │                   │
├──────────┴──────────┴──────────┴───────────────────┤
│              MySQL + Redis + MinIO + MQTT           │
└─────────────────────────────────────────────────────┘
```

## 二、系统管理 (blade-system)

系统的核心基础模块，管理用户、权限、租户等。

### 2.1 用户管理
- **页面**: `系统管理 → 用户管理`
- **功能**: 
  - 用户增删改查，支持 Excel 导入导出
  - 重置密码、修改密码
  - 分配角色（一个用户可有多个角色）
  - 查看/编辑个人信息
- **API**: `/user/*`

### 2.2 角色管理
- **页面**: `权限管理 → 角色管理`
- **功能**:
  - 角色增删改查，树形展示
  - **授权**: 给角色分配菜单、数据权限、API权限
  - 角色别名管理
- **API**: `/role/*`
- **注意**: 只有管理员可创建/删除角色

### 2.3 菜单管理
- **页面**: `系统管理 → 菜单管理`
- **功能**:
  - 菜单树增删改查（支持懒加载）
  - 菜单分为目录、菜单、按钮三种类型
  - 配置路由路径、图标、排序
- **API**: `/menu/*`
- **注意**: 前端路由和按钮权限由后端菜单数据动态生成

### 2.4 部门管理
- **页面**: `系统管理 → 部门管理`
- **功能**:
  - 部门树形结构管理（支持懒加载）
  - 部门增删改查
  - 部门下拉选择器
- **API**: `/dept/*`

### 2.5 租户管理 (SaaS 核心)
- **页面**: `系统管理 → 租户管理`
- **功能**:
  - 租户增删改查
  - **回收站**: 软删除后进入回收站，可恢复或永久删除
  - **授权设置**: 配置租户账号数、到期时间、套餐包
  - 租户数据源配置（支持独立数据库隔离）
- **API**: `/tenant/*`, `/tenant-package/*`, `/tenant-datasource/*`
- **关键机制**: 所有业务数据通过 `tenant_id` 字段隔离

### 2.6 字典管理
- **页面**: `系统管理 → 系统字典` / `业务字典`
- **功能**:
  - 字典父子树管理
  - 系统字典（全局）+ 业务字典（业务域）
  - 前端下拉框选项的数据来源
- **API**: `/dict/*`, `/dict-biz/*`

### 2.7 参数管理
- **页面**: `系统管理 → 参数管理`
- **功能**: 系统全局参数键值对配置，修改后自动清除缓存
- **API**: `/param/*`

### 2.8 岗位管理
- **页面**: `系统管理 → 岗位管理`
- **功能**: 岗位/职位增删改查
- **API**: `/post/*`

### 2.9 行政区划
- **页面**: `基础配置 → 行政区划`
- **功能**: 省市区树形管理，支持懒加载和 Excel 导入
- **API**: `/region/*`

### 2.10 顶部菜单
- **页面**: `系统管理 → 顶部菜单`
- **功能**: 顶部导航栏菜单管理，可分配侧边菜单
- **API**: `/topmenu/*`

### 2.11 权限管理高级
- **页面**: `权限管理 → API权限` / `数据权限`
- **API权限**: 定义哪些 API 端点可被保护，分配给角色
- **数据权限**: 定义数据级别的访问规则
- **API**: `/api-scope/*`, `/data-scope/*`

### 2.12 客户端管理
- **页面**: `系统管理 → 客户端管理`
- **功能**: OAuth2 客户端应用注册管理

## 三、设备管理 (blade-device)

平台的核心业务模块，管理所有工牌设备和相关数据。

### 3.1 设备信息
- **页面**: `设备管理 → 设备信息`
- **功能**:
  - 设备增删改查 + Excel 批量导入/导出
  - **设备分配**: 管理员将设备分配给用户
  - **用户自绑定**: 用户自行绑定/解绑设备（员工端）
  - 设备状态查看：在线状态、GPS状态、电量、存储空间、固件版本
  - 设备使用统计：在线统计、分配统计
- **API**: `/deviceInfo/*`

### 3.2 设备 GPS 日志
- **页面**: `设备管理 → GPS日志`
- **功能**: 查看设备 GPS 轨迹历史数据，支持导出
- **API**: `/deviceGpsLog/*`

### 3.3 设备上报日志
- **页面**: `设备管理 → 设备日志`
- **功能**: 查看设备上报的原始日志（错误/警告/消息）
- **API**: `/deviceLog/*`

### 3.4 设备录音
- **页面**: `设备管理 → 录音记录` / `录音合并`
- **功能**:
  - 查看设备录音列表，支持**在线播放**和下载
  - **ASR 语音转文字**: 查看转写结果，可重新转写
  - **录音合并**: 将设备上传的分段录音合并
  - 转存至 MinIO 对象存储
  - **音频波形**: 生成并显示音频波形图
  - 统计：录音数量、总时长、日期范围
- **API**: `/deviceVocRecord/*`, `/deviceVocRecordCombine/*`

### 3.5 声纹库
- **页面**: `设备管理 → 声纹库`
- **功能**:
  - **注册声纹**: 上传音频文件注册用户声纹
  - **声纹分析**: 对录音进行声纹比对分析
  - **重新匹配**: 对已有录音重新匹配说话人
  - **归属员工识别**: 识别录音中的说话人归属
  - 查看匹配结果
- **API**: `/voiceprintLibrary/*`

### 3.6 工牌打卡 ⭐
- **页面**: 
  - `设备管理 → 打卡点管理` — 创建/导入/启用打卡点
  - `设备管理 → 问题打卡点` — 修复坐标匹配失败的点
  - `设备管理 → 打卡记录` — 查看打卡记录
  - `设备管理 → 实时监控` — 大屏监控打卡状态
- **功能**:
  - 手动创建（地图选点）+ Excel 批量导入
  - 前端高德地图自动地址→坐标匹配（POI+Geocoder）
  - 双模式管控：无时间窗口（启用/停用）、有时间窗口（启动/结束）
  - 实时检测：设备 GPS 到达时即时判定（Haversine + 停留时长）
  - 4 种实时状态：已打卡 / 停留中 / 未打卡 / 离线
  - 监控大屏：设备树(按部门分组) + 地图 + 状态表，30秒刷新
- **完整说明**: 参见 [[checkin-user-manual]]

### 3.7 告警事件
- **页面**: `设备管理 → 告警事件`
- **功能**: 查看设备上报的异常告警（SD卡满、电量低、设备异常等）
- **API**: `/event/*`

### 3.8 案例库
- **页面**: 
  - `设备管理 → 案例详情` — 查看案例，支持审核和学习提交
  - `设备管理 → 案例库` — 案例仓库管理
- **功能**: 优秀/典型案例的收录、审核、AI 学习
- **API**: `/caseDetail/*`, `/caseStorage/*`

### 3.9 客户信息
- **页面**: `设备管理 → 客户信息`
- **功能**: 客户信息管理，支持下拉搜索
- **API**: `/customerInfo/*`

### 3.10 录音标注
- **页面**: `设备管理 → 录音标注`
- **功能**: 录音标注记录管理，支持审核流程
- **API**: `/vocAnnotationRecord/*`

### 3.11 设备使用统计
- **页面**: `设备管理 → 设备使用`
- **功能**: 查看设备在线/离线使用记录，统计在线率
- **API**: `/deviceUsage/*`

### 3.12 统计接口
- **API**: `/statistic/*`
  - 设备数量统计
  - ASR 转写量统计
  - 质检评分统计

## 四、设备控制 (blade-record)

设备实时通信控制层，通过 MQTT 向设备下发指令。

### 4.1 设备控制
- **页面**: `设备管理 → 设备控制`
- **功能**:
  - **远程录音**: 下发录音指令（按类型）
  - **定位查询**: 请求设备当前 GPS 位置
  - **远程重启**: 重启设备
  - **录音补传**: 按时间段补传录音文件
  - **录音列表**: 获取设备上的录音文件列表
  - **录音删除**: 删除设备上的指定录音
  - **模式设置**: 设置设备控制模式
  - **配置同步**: 同步配置到设备
  - **配置任务**: 创建/查询设备配置下发任务和日志
- **API**: `/control/*`

### 4.2 心跳日志
- **页面**: `设备管理 → 心跳日志`
- **功能**: 查看设备心跳上报记录
- **API**: `/deviceHeartbeatLog/*`

### 4.3 设备使用记录
- **功能**: 自动记录设备上线/下线时间、在线时长
- **机制**: 200 秒无心跳 → 判定离线

## 六、AI 质检 (blade-quality)

平台最复杂的业务模块，实现 AI 驱动的语音质检评分和分析。

### 6.1 质检模型体系

```
行业 (Industry) → 模型类型 (ModelType) → 模型模板 (ModelTemplate)
                                              ↓
                                         质检模型 (Model)
                                              ↓
                              维度 (Dimension) → 细则 (Item) → 评分标准 (Criteria)
                                              ↓
                                          扣分详情 (DeductPoints)
```

#### 行业管理
- **页面**: `AI质检 → 行业管理`
- **功能**: 定义质检行业分类

#### 模型类型
- **页面**: `AI质检 → 模型类型`
- **功能**: 质检模型的分类标签

#### 模型模板
- **页面**: `AI质检 → 模型模板`
- **功能**: 预置的质检模型模板，可复制创建新模型

#### 质检模型 (核心)
- **页面**: `AI质检 → 质检模型`
- **功能**:
  - 模型增删改查
  - **启用/停用**: 控制模型是否生效
  - **从模板创建**: 基于模板快速生成模型
  - **模板复制**: 复制已有模型配置
  - 模型命中统计
- **模型编辑器**: `/quality/qualityModelEdit/:modelId`

#### 质检维度
- **功能**: 质检评价维度定义

#### 质检细则
- **功能**: 具体的质检检查项

#### 评分标准
- **功能**: 细则对应的评分规则

#### 扣分详情
- **功能**: 质检扣分明细管理

### 6.2 通用质检
- **页面**: `AI质检 → 通用质检评分`
- **模型编辑器**: `/quality/qualityCommonModelEdit/:modelId`

### 6.3 行业质检
- **页面**: `AI质检 → 行业质检`
- **模型编辑器**: `/quality/qualityCommonIndustryModelEdit/:modelId`

### 6.4 通用分析模型
- **页面**: `AI质检 → 通用洞察配置`
- **功能**: 通用分析模型配置

### 6.5 客户洞察模型
- **页面**: `AI质检 → 客户洞察配置`
- **功能**: 客户分析模型配置，支持树形字典+批量保存
- **模型编辑器**: `/quality/customerModelEdit/:modelId`

### 6.6 录音提炼模型
- **模型编辑器**: `/quality/commonModelEdit/:modelId`

## 十四、常见操作流程

### 14.1 新员工入职配置
```
1. 系统管理 → 用户管理 → 新增用户
2. 权限管理 → 角色管理 → 分配角色给用户
3. 设备管理 → 设备信息 → 分配设备给用户
4. (可选) 声纹库 → 注册用户声纹
```

### 14.2 发布打卡任务
```
1. 设备管理 → 打卡点管理 → 新增/批量导入
2. 地图选点或上传 Excel
3. 等待坐标自动匹配（失败的到问题页手动修复）
4. 点击「启用」
5. 点击「监控」查看实时打卡状态
```

### 14.3 质检评分流程
```
1. AI质检 → 行业管理 → 创建行业（如：客服/销售）
2. AI质检 → 质检模型 → 从模板创建或新建
3. 配置维度 → 细则 → 评分标准 → 扣分规则
4. 启用模型
5. 查看 AI质检 → 质检结果（自动评分）
6. AI质检 → 质检详情 → 人工复核/学习
```

### 14.4 发起请假审批
```
1. 工作流 → 请假申请 → 填写表单 → 提交
2. 审批人登录 → 待办任务 → 处理请假 → 同意/驳回
3. 发起人 → 已发任务 → 查看审批进度
```

### 14.5 代码生成
```
1. 开发工具 → 数据源 → 配置数据库连接
2. 开发工具 → 数据模型 → 从数据库导入表结构
3. 开发工具 → 代码生成 → 选择表 → 生成代码
4. 下载生成的代码包 → 放入对应模块
```

## 十五、常见问题

### Q1: 设备离线看不到数据？
- 检查设备心跳是否到达（心跳日志页查看）
- 200 秒无心跳即判定离线
- 确认 MQTT 连接正常

### Q2: 录音无法播放？
- 检查录音文件是否已上传到 MinIO
- 可尝试「转存至 MinIO」操作
- 检查对象存储配置是否启用

### Q3: 权限按钮看不到？
- 检查菜单管理中是否配置了按钮权限
- 检查当前角色是否分配了对应菜单/按钮
- 某些页面临时写死了权限（如打卡页）

### Q4: AI 质检没有结果？
- 确认质检模型已启用
- 确认录音已上传且完成 ASR 转写
- 可手动点击「重新质检」

### Q5: 数据隔离机制？
- 平台使用多租户 Saas 架构
- 所有业务表通过 `tenant_id` 字段隔离
- 支持独立数据库模式（租户数据源配置）
